# IA-test

Repositorio para comparar modelos de IA locales actuando como agentes de desarrollo.

Cada carpeta contiene una prueba generada por un modelo distinto.

## Modelos a probar

- qwen2.5-coder-7b
- qwen2.5-coder-3b
- deepseek-coder-6.7b
- codegemma-7b
- llama3.1-8b
- mistral-7b
- deepseek-r1-7b

## Criterios de evaluación

- Funcionalidad
- Calidad del código
- Orden de carpetas
- Diseño frontend
- Coherencia frontend/backend
- Cantidad de correcciones manuales
- Facilidad para ejecutar
- Capacidad de corregir errores
